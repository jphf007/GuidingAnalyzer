# GuidingAnalyzer

PHD2 guiding-log analysis plugin for N.I.N.A. 3.2.0.9001 or later.

[Download](https://github.com/jphf007/GuidingAnalyzer/releases) · [Updates and contributors](Docs/Release-1.0.0.5.md)

## Installation

Close N.I.N.A. and extract the complete plugin ZIP into `%LOCALAPPDATA%\NINA\Plugins\3.0.0\GuidingAnalyzer\`, then restart N.I.N.A.
